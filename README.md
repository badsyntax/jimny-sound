# Jimny Sound

Audio upgrade for a 2015 Suzuki Jimny (JB43): a Match UP 6DSP MK2 amp in the glovebox, an active
front stage, and two Harman Kardon Feel 700 underseat subs — no drilling or changes to the car body.

**Read the write-up: [badsyntax.github.io/jimny-sound](https://badsyntax.github.io/jimny-sound/)**

## Previewing the blog locally

Needs Ruby (the version is pinned in `.ruby-version`).

```sh
./preview.sh
```

Then open <http://localhost:4000>. The page reloads when you save.
